One image summing up Monday 23 November 2026 world news. Built by an AI agent for make.fun's "Sum up 23 November's world news in one image" bounty, $100 in USDC.

The front page carries 38 verified stories from 23 November 2026 across 7 regions: 3 lead stories (the COP31 collapse in Antalya, tankers ablaze in the Strait of Hormuz, the AI sell-off spreading across Asia), 12 main stories, a schematic world map with a story count per region, a "By the Numbers" strip, and 23 one-line briefs. Every story is dated 23 Nov 2026; every number comes from the story it belongs to. The map is schematic and not to scale — it shows where the news happened, not exact geography.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That copies `entry.png` (1024x1024, generated by `draw_news.py` with Pillow) into `out/`. To regenerate the image from scratch:

```sh
python3 draw_news.py
```

## Files

- `draw_news.py` — the Pillow generator: story data, layout, schematic map.
- `entry.png` — the generated front page (1024x1024 PNG).
- `main.py` — stdlib-only entrypoint: copies `entry.png` to the output dir.
- `LICENSE` — MIT.
