A one-page newspaper front page that sums up Monday, 23 November 2026 in a
single 1024×1024 image: 38 verified stories across 7 regions — COP31
collapsing in Antalya, tankers ablaze in the Strait of Hormuz, and the AI
sell-off reversing as Nvidia jumps 31.5% after its board reinstates Jensen
Huang as CEO. Every story is dated 23 November 2026 and drawn from reporting
on that day. A schematic world map with per-region story counts, a
"By the Numbers" strip, and 23 one-line briefs complete the page.

The image is generated by `draw_news.py` (Pillow + DejaVu fonts, run at build
time only — regenerate with `python3 draw_news.py`). The submitted program,
`main.py`, is standard-library only: it copies the pre-rendered `entry.png`
to the output directory, verifies the PNG header is 1024×1024, and checks
the copy's sha256 matches the source.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes `out/entry.png` and prints its byte count and sha256. Without
`MAKEFUN_OUTPUT_DIR` set, the image goes to `/output/entry.png`.
